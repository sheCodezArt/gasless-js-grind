## HTML & CSS Mastery Outline

### Phase 1: HTML Foundations
- Document structure: `doctype`, `html`, `head`, `body`, meta tags, viewport, charset
- Text: headings, paragraphs, inline vs block, `strong`/`em`, `br`/`hr`, entities
- Links & media: `a` (absolute/relative/anchors), `img`, `picture`/`srcset`, `video`, `audio`, `iframe`
- Lists & tables: `ul`/`ol`/`dl`, `table`, `thead`/`tbody`, `colspan`/`rowspan`
- Attributes: `id`, `class`, `data-*`, `hidden`, `title`

### Phase 2: Semantic HTML & Accessibility
- Landmarks: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Heading hierarchy, `figure`/`figcaption`, `time`, `address`, `details`/`summary`, `dialog`
- Alt text, labels, focus order, keyboard navigation
- ARIA basics (and when *not* to use it), screen reader testing
- Color contrast, reduced motion, skip links

### Phase 3: Forms
- `form`, `input` types, `label`, `select`, `textarea`, `fieldset`/`legend`
- Built-in validation: `required`, `pattern`, `min`/`max`, `minlength`
- `datalist`, `output`, `progress`, `meter`
- Form accessibility and error messaging

### Phase 4: CSS Core
- Syntax, selectors, specificity, the cascade, inheritance
- Selector types: element, class, ID, attribute, combinators, pseudo-classes, pseudo-elements
- Modern selectors: `:is()`, `:where()`, `:has()`, `:not()`, `:focus-visible`
- Units: `px`, `rem`, `em`, `%`, `vw`/`vh`, `dvh`, `ch`, `fr`
- Colors: hex, `rgb`, `hsl`, `oklch`, `currentColor`, gradients
- Typography: `font-family`, `@font-face`, line-height, letter-spacing, `text-wrap`
- Backgrounds, borders, shadows, `border-radius`, `outline`
- Resets, `box-sizing`, `box-sizing: border-box` everywhere

### Phase 5: The Box Model & Flow
- Margin, padding, border, margin collapsing
- `display`: block, inline, inline-block, none
- `position`: static, relative, absolute, fixed, sticky
- `z-index` and stacking contexts
- `overflow`, `float` (legacy), `aspect-ratio`, `object-fit`

### Phase 6: Layout
- **Flexbox:** axes, `justify-content`, `align-items`, `gap`, `flex-grow/shrink/basis`, `flex-wrap`, `order`
- **Grid:** `grid-template-columns/rows`, `fr`, `repeat()`, `minmax()`, `auto-fit`/`auto-fill`, named areas, `subgrid`
- Centering every way, holy grail layout, card grids, sticky footers
- Multi-column layout

### Phase 7: Responsive Design
- Mobile-first approach
- Media queries: width, `prefers-color-scheme`, `prefers-reduced-motion`, `hover`
- Container queries
- Fluid sizing: `clamp()`, `min()`, `max()`
- Responsive images and typography
- Testing on real devices and DevTools

### Phase 8: Modern CSS Architecture
- Custom properties (CSS variables), theming, dark mode
- `calc()`, nesting, `@layer`, `@scope`
- Logical properties (`margin-inline`, `padding-block`)
- Naming and organization: BEM, utility-style, component-based
- File structure, partials, and keeping specificity low

### Phase 9: Transitions, Animation & Effects
- `transition`, timing functions, `transform` (translate, rotate, scale)
- `@keyframes`, `animation` properties
- `filter`, `backdrop-filter`, `mix-blend-mode`, `clip-path`, masks
- Scroll-driven animations, scroll snap, view transitions
- Performance: animate `transform` and `opacity`, `will-change`

### Phase 10: Advanced HTML & Platform Features
- SVG (inline, sprites, styling with CSS)
- `canvas` basics
- `template`, `slot`, and Web Components intro
- `link rel` (preload, prefetch), `loading="lazy"`
- SEO basics: meta tags, Open Graph, structured data

### Phase 11: Tooling & Craft
- DevTools mastery: inspector, computed styles, layout overlays, device mode
- Validators, Lighthouse, accessibility audits
- Browser compatibility: Can I Use, `@supports`, progressive enhancement
- Git workflow for front-end projects
- Cross-browser quirks and debugging methods
